# Harmonia AI — MVP Android

Prototype natif Android sans AndroidX pour maximiser la compatibilité avec AIDE.

## Inclus
- Onboarding
- Découverte de profils
- Score de compatibilité IA multidimensionnel
- Affinité visuelle personnalisée (conceptuelle, pas une note universelle de beauté)
- Explication du score
- Liste de meilleurs matchs
- Assistant IA conversationnel simulé localement
- Profil et transparence sur les critères

## Compilation
Le projet se compile avec Gradle/Android SDK. GitHub Actions génère un APK debug installable.
